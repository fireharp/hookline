## HL-STEER-001: Line Count Soft Review

**Project fixture:** temporary smoke-bench repo with one cohesive Markdown file.

**Initial state**

- `cohesive-reference.md` exists with 501 lines.
- Configured soft target is 500 lines.

**Replay messages**

| Actor | Message |
| --- | --- |
| agent | I created a cohesive reference file that is just over 500 lines. |
| hookline | This is an advisory line-count finding; review split versus keep. |
| agent | I reviewed the file and kept it together because it has one responsibility. |

**Hook/check evidence**

```json
{
  "event": "scan lines",
  "input": {"path": "cohesive-reference.md", "lines": 501, "limit": 500},
  "output": {
    "findings": [
      {
        "path": "cohesive-reference.md",
        "lines": 501,
        "limit": 500,
        "severity": "advisory"
      }
    ]
  },
  "effect": "advisory evidence; no Stop continuation"
}
```

**Final state**

- `cohesive-reference.md` remains one file.
- Stop evaluation returns allow.
- The line-count finding remains visible as advisory evidence.
- Verification: line scan reports one advisory finding; Stop does not request continuation.

## HL-STEER-002: Env Leak

**Project fixture:** temporary smoke-bench repo with local `.env` and staged
`README.md`.

**Initial state**

- `.env` contains `LOCAL_PROJECT_ROOT=/Users/myuser/Work/private-client`.
- `README.md` staged that literal path value.

**Replay messages**

| Actor | Message |
| --- | --- |
| agent | I staged a local project path from `.env`. |
| hookline | `LOCAL_PROJECT_ROOT` appears in staged additions; path value is redacted. |
| agent | I replaced the literal with `${LOCAL_PROJECT_ROOT}`. |

**Hook/check evidence**

```json
{
  "event": "scan secrets",
  "input": {"staged_file": "README.md", "env_key": "LOCAL_PROJECT_ROOT"},
  "output": {
    "env_leaks": [
      {"key": "LOCAL_PROJECT_ROOT", "redacted": "/Us...ent (33 chars)"}
    ]
  },
  "effect": "pre-commit failure until the literal is removed"
}
```

**Final state**

- `README.md` contains `${LOCAL_PROJECT_ROOT}` instead of the literal path.
- Verification: secret guard reports zero env leaks.

```json
}
```

**Final state**

- `notes.md` diff is reduced to 20 added lines.
- Verification: `PostToolUse` no longer returns the large-diff rule.

## HL-STEER-006: Stop Continuation

**Project fixture:** temporary smoke-bench repo with an unresolved TODO at a
`Stop` event.

**Initial state**

- `notes.md` has a newly added TODO line.
- Agent attempts to stop.
- `stop_hook_active` is `false`.

**Replay messages**

| Actor | Message |
| --- | --- |
| agent | I am done. |
| hookline | Before stopping, address or justify the new TODO/FIXME. |
| agent | I replaced the TODO with a concrete follow-up reference. |

**Hook/check evidence**

```json
{
  "event": "Stop",
  "input": {
    "hook_event_name": "Stop",
    "stop_hook_active": false,
    "cwd": "<fixture>"
  },
  "output": {
    "decision": "block",
    "reason": "Before stopping, address or explicitly justify: new TODO/FIXME added"
  },
  "effect": "continuation prompt; not a hard failure"
}
```

**Final state**

- TODO line removed.
- Concrete follow-up reference is present.
- Second `Stop` evaluation returns allow.
- Verification: Stop does not request continuation after the correction.

## Protocol Note

`Stop` uses Codex's continuation protocol when the agent must take another pass.
`PostToolUse` uses additional context so tool output remains visible while the
agent is steered toward the next action. Hookline reports the issue; the replay
evidence shows the follow-up action and the final clean result.
